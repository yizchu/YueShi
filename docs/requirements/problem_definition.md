# 教学能力评估智能体

> 面向大学生家教的**教学能力评估方法**研究
> 第一版限定范围：**初中学段 × 数学学科**

---

## 零、方案总览

**一句话**：给被试者一道初中数学讲题，提交逐字讲稿；再由系统抽取 3 类虚拟学生各提 1 个问题，被试依次解答；最后由 LLM 按「通用标准 + 特殊标准 + 问答标准」评分，输出评级与改进建议。

```
① 抽题（不提供学生人设）
      ↓
② 被试自行备课
      ↓
③ 提交逐字讲稿
      ↓
④ 系统抽 3 类学生人设 → 各提 1 问（共 3 问，保证合理且互不重复）
      ↓
⑤ 被试依次解答 3 轮
      ↓
⑥ LLM 评分：通用标准（3 项）+ 特殊标准（采分点）+ 问答标准（3 项）
      ↓
⑦ 输出：评级 + 分项得分 + 改进建议（如有）
```

**研究重心**：纯文本（讲稿 + 问答）。听觉、视觉、视频转录属后续扩展，不在第一版范围。

## 一、5W1H 报告

### 1.1 What —— 做什么

**产品**：面向大学生家教的**讲题教学能力评估智能体**。

**评估材料**：

| 材料 | 产生方式 | 内容 |
|---|---|---|
| **逐字讲稿** | 被试备课手写提交 | 完整讲题过程 |
| **3 轮问答** | 系统提问 → 被试文字解答 | 针对 3 类虚拟学生的提问 |

**评分标准（两层 + 问答）**：

- **通用标准**（讲稿）：教学目标与设计 / 教学内容与学科素养 / 教学实施与方法
- **特殊标准**（讲稿）：针对该讲题的**采分点**，不满足不能给分
- **问答标准**（3 轮问答）：应答切题 / 因材施教 / 启发引导（本方案补充）

**产出**：

1. **评级**（优秀 / 良好 / 合格 / 待改进 / 不合格）
2. 分项得分与逐条理由（通用 3 项、问答 3 项、采分点达成情况）
3. **改进建议**（仅当存在不足时给出）

### 1.2 Why —— 为什么做

**核心矛盾**：家长挑选大学生家教时，现有信息只能证明他"**会做题**"，不能证明他"**会讲课**"。

| 现有依据 | 问题 |
|---|---|
| 看学校、专业、高考分数 | 只反映做题能力，与讲解能力不相关 |
| 靠中介推荐 | 主观、无标准、不可比 |
| 靠试课试错 | 家长要付出真实时间与金钱成本 |
| 靠同学转介绍 | 覆盖面窄，无法规模化 |

**为什么用"讲题 + 虚拟学生提问"**：

- **讲题**是最能暴露教学能力的场景——能否讲清目标、组织环节、语言表达，一次讲稿就能看出来；
- **虚拟学生提问**模拟真实家教中的追问，考察**因材施教**与**临场应答**，这是纯讲稿考不出的；
- **不提供学生人设**（抽题阶段），避免被试"为特定学生定制"，保证讲稿反映其通用教学能力。

### 1.3 Who —— 谁参与

| 角色 | 诉求 | 位置 |
|---|---|---|
| **被试者**（大学生） | 拿到可信评级；知道短板在哪 | 主要使用者 |
| **虚拟学生**（LLM 扮演） | — | 系统生成的提问方，5 类人设 |
| **管理员** | 维护题目库、评分标准、示例 | 配置方 |
| **下游消费系统**（家教平台） | 获取教学能力信号 | 结果消费者 |

> **注意**：不设"人工复核"角色——人工复核属下游产业环节，不在本研究范围。但输出必须**可复核**（含理由与证据）。

### 1.4 Where —— 在哪里发生

- **形式**：线上、异步、纯文本交互（提交讲稿 + 文字答题）
- **业务位置**（由下游平台决定接入点）：

```
注册 → 实名/学籍认证 → 【本评估智能体】 → 评级/认证 → 推荐池
```

- **本项目不负责**平台搭建、订单、支付、推荐算法。

### 1.5 When —— 何时发生

| 时点 | 说明 |
|---|---|
| **触发** | 大学生申请成为初中数学家教时（由下游决定） |
| **单次时长** | 约 30~45 分钟（备课 + 写讲稿 + 3 轮问答） |
| **重试** | 允许再次评估（次数与冷却期由配置决定） |

### 1.6 How —— 怎么做

**第一阶段：讲稿**

1. 从 9 个真题中抽 1 题（**不提供学生人设**）
2. 被试自行备课，提交**逐字讲稿**

**第二阶段：3 轮问答**

3. 系统从 **5 类学生人设**中抽 **3 类**（互不重复）
4. LLM 为每类人设生成 1 个问题，**共 3 问**，必须满足：
   - **合理**：问题与该学生类型特征吻合、与讲题内容相关
   - **互不重复**：3 问考察点不重叠
   - 生成问题时同步产出「**参考应答要点**」（供评分锚定）
5. 被试**依次**作答（一轮一问一答）

**第三阶段：评分**

6. LLM 按三层标准评分：
   - **通用标准**（3 项 × 1~5 分）
   - **特殊标准**（采分点，门槛性）
   - **问答标准**（3 项 × 1~5 分）
7. 合成评级，生成改进建议

**技术实现**：全部走 LLM（API），不自研模型。题目库、评分标准、示例均为可配置资产。

## 二、产品描述

### 2.1 评估流程（详细）

| 步骤 | 动作 | 是否给被试看 |
|---|---|---|
| 1 | 抽题（9 个真题之一） | 只给**题干**，不给学生人设 |
| 2 | 备课 | — |
| 3 | 提交逐字讲稿 | — |
| 4 | 抽 3 类学生人设 + 生成 3 个问题 | **讲稿提交后**才揭示第 1 问 |
| 5 | 第 1 轮：回答问题 1 | 逐轮揭示 |
| 6 | 第 2 轮：回答问题 2 | |
| 7 | 第 3 轮：回答问题 3 | |
| 8 | 评分 + 报告 | 全部答完后 |

> **关键约束**：3 个问题必须在讲稿提交后才揭示，且**逐轮揭示**（答完第 1 问才见第 2 问），避免一次性看到全部问题后"通盘作答"，保住临场应答的真实性。

### 2.2 题目范围

- **学段学科**：初中数学
- **题库规模（第一版）**：**9 个真题**，取自《初中数学真题整合+万能模板》的「真题精选」部分
- **每题配套资产**：
  - 题干
  - 年级 / 知识点
  - **特殊标准（采分点清单）**——该题必须讲到的点 + 易错点
  - 参考讲稿要点（供评分参考）

> 只做 9 个真题，是为了把每道题的采分点打磨到位，而不是铺量。

### 2.3 虚拟学生人设（5 类）

详见 [`虚拟学生类型划分.md`](../../虚拟学生类型划分.md)。摘要：

| 类型 | 典型特征 | 提问视角 |
|---|---|---|
| **1. 概念严谨型** | 关注定义边界、条件完整性，能发现老师表述漏洞 | 挑定义/表述的不严谨处 |
| **2. 基础困惑型** | 学习较慢、理解力弱 | 要求拆解基础步骤、解释符号含义 |
| **3. 迁移应用型** | 关注"怎么用"、联系生活与变式 | 问实际应用、读法、变式延伸 |
| **4. 拓展挑战型** | 学有余力、想追问后续 | 问边界情形（负数、小于 1 的数）、后续知识 |
| **5. 批判反思型** | 追问方法必要性与适用条件 | 问"为什么这样规定""一定更好吗" |

**抽取规则**：从 5 类中随机抽 **3 类**（不重复），每类提 1 问。

**问题生成要求**：

1. **合理**：符合该人设特征；与讲题内容相关（可参考讲稿，针对老师实际讲的表述提问）
2. **互不重复**：3 问的考察点不重叠（如不能 3 问都在问"A 的范围"）
3. **可答**：在初中数学知识范围内，被试有能力回答
4. 同步生成「**参考应答要点**」，供评分锚定

### 2.4 评分标准

#### A. 通用标准（讲稿，3 项，各 1~5 分）

| 编号 | 标准 | 观察内容 |
|---|---|---|
| **G1** | **教学目标与设计** | ① 是否让学生知晓本节课的学习目标<br>② 教学环节（导入 / 新授 / 练习 / 小结）是否围绕目标展开<br>③ 时间分配是否科学<br>④ 逻辑是否清晰 |
| **G2** | **教学内容与学科素养** | ① 是否凸显本学科的**核心思想、方法和逻辑关系**，而不仅是知识点罗列<br>② 能否适当引入新知识、新技术，理论联系实际 |
| **G3** | **教学实施与方法** | ① 语言是否清晰、简洁、有逻辑<br>② 有无适当的**提问、候答、理答**<br>③ 能否激发深度思考、促进真实讨论 |

#### B. 特殊标准（讲稿，采分点，门槛性）

针对**特定讲题**的评分标准，以**采分点**形式呈现：

| 考察方向 | 说明 |
|---|---|
| 科学性与准确性 | 教学内容是否科学、准确，无知识性错误 |
| 重点与难点 | 重点是否突出、难点处理是否得当 |
| 知识点覆盖 | 该讲的知识点是否都讲到 |
| 易错点预判 | 学生可能犯的错，是否预判到并提前强调 |

**规则**：采分点**不满足就不能给分**（门槛/硬扣分，不是主观加减）。

> **说明**：学科知识本身默认被试已掌握（见 [`基本假设.txt`](../../docs/基本假设.txt)）。这里评的不是"他会不会"，而是"**他有没有把它讲出来**"——漏讲关键知识点，就是教学能力问题。

#### C. 问答标准（3 轮问答，3 项，各 1~5 分）【本方案补充】

| 编号 | 标准 | 观察内容 |
|---|---|---|
| **Q1** | **应答切题** | ① 是否准确理解学生问的是什么<br>② 是否**正面回应**，不含糊、不回避、不答非所问<br>③ 回应是否覆盖问题的核心 |
| **Q2** | **因材施教** | 是否针对该学生类型的特点调整回应方式：<br>· 概念严谨型 → 给出严谨、边界清晰的回答（承认瑕疵并修正）<br>· 基础困惑型 → 降维、拆解、用具体数字说明<br>· 迁移应用型 → 联系实际、给变式<br>· 拓展挑战型 → 适当延伸但**不超纲**<br>· 批判反思型 → 讲清"为什么"，说明规定的必要性 |
| **Q3** | **启发引导** | ① 是引导思考，还是直接灌输答案<br>② 表达是否清晰易懂<br>③ 是否照顾到该学生的接受能力 |

> **问答评分锚点**：每个问题生成时同步产出的「参考应答要点」，作为 Q1/Q2/Q3 评分的参考依据。

#### D. 评分方式

- 由大模型结合三类输入做**主观评分**：
  1. **优质模板**（理想答案参照）
  2. **存在典型问题的讲法示例**（低分参照）
  3. **实际讲稿 / 实际回答**
- 每项给出**分数 + 文字理由 + 原文证据**
- 1~5 分的**档位描述待细化**（后续设计）

### 2.5 评级与输出

**评级（5 档）**：

| 评级 | 含义 |
|---|---|
| **优秀** | 各标准表现突出，无明显短板 |
| **良好** | 整体达标，个别项有提升空间 |
| **合格** | 基本达标，存在可改进之处 |
| **待改进** | 存在明显短板，需针对性提升 |
| **不合格** | 核心采分点缺失或存在严重问题 |

**输出内容**：

```
评级：良好
├── 讲稿得分
│   ├── G1 教学目标与设计   4 分 + 理由 + 证据
│   ├── G2 教学内容与学科素养 3 分 + 理由 + 证据
│   ├── G3 教学实施与方法    4 分 + 理由 + 证据
│   └── 特殊标准（采分点）
│       ├── [覆盖] 用数据情境引出大数书写不便
│       ├── [覆盖] 复习 10 的乘方搭桥
│       ├── [未覆盖] 强调 A 的取值范围（核心）  ← 硬扣分
│       └── ...
├── 问答得分
│   ├── Q1 应答切题        4 分 + 理由 + 证据
│   ├── Q2 因材施教        3 分 + 理由 + 证据
│   └── Q3 启发引导        4 分 + 理由 + 证据
└── 改进建议（如有）
    ├── 【讲稿】补充 A 的取值范围（1≤A<10），并举反例辨析
    ├── 【问答】对"概念严谨型"学生的追问，应先承认表述瑕疵再修正
    └── ...
```

> **改进建议规则**：仅当发现不足时给出；若各项优秀则可为空。

### 2.6 范围边界

**做（In Scope）**

- 初中数学讲题（9 个真题）
- 逐字讲稿评估
- 3 类虚拟学生 × 3 轮问答评估
- 通用标准 + 特殊标准（采分点）+ 问答标准评分
- 评级与改进建议

**不做（Out of Scope）**

| 排除项 | 说明 |
|---|---|
| **学科知识准入测试** | 默认被试已掌握学科知识 |
| **人工复核 / 申诉** | 属下游产业环节 |
| **听觉评估** | 连贯性、口齿清晰等（后续扩展） |
| **视觉评估** | 是否读稿、板书质量等（后续扩展） |
| **音视频采集 / 视频转录** | 第一版纯文本（后续扩展） |
| 其他学段学科 | 仅初中数学 |
| 平台业务功能 | 订单、支付、IM、推荐算法 |

### 2.7 后续扩展（不在第一版）

| 扩展 | 内容 |
|---|---|
| **听觉模块** | 是否连贯、口齿是否清晰、语速节奏等 |
| **视觉模块** | 是否读稿、板书是否规范清晰等 |

## 三、关键设计决策

| 决策 | 理由 |
|---|---|
| 抽题时**不提供学生人设** | 避免为特定学生定制，保证讲稿反映通用教学能力 |
| **讲稿先交、问题后揭示** | 保住临场应答的真实性，防止"看题作答" |
| 固定 **3 轮**问答 | 覆盖 3 类学生，成本可控，评估结构一致可比 |
| 人设 **5 选 3** | 单次不重复，多次评估可覆盖全部类型 |
| 问题生成同步产出**参考应答要点** | 为问答评分提供锚点，提高一致性（参见 qi-2025：无参照时 LLM 评分易失效） |
| 特殊标准用**采分点 + 门槛** | "漏讲关键知识点"是硬伤，不能用其他项的高分掩盖 |
| 全部走 **LLM API** | 不自研模型，聚焦评分标准与方法本身 |
| 保留 **1~5 分制** | 0-5 档人机一致性最高（参见 li-2026） |
