## 2. 一句话概括

用 **rubric + LLM（Kimi）** 给大学数学/物理课程的**教学视频转写**打分（1~5 档），通过**反复评估检测幻觉**、用**与期末成绩的相关性**做效度验证——证明 LLM 评教学内容可行，且**评分示例（scoring examples）是成败关键**。

---

## 3. 核心问题（原文 RQ）

- **RQ1**：如何识别 LLM 在教育评估中的**幻觉**，从而设计可信的 rubric？
- **RQ2**：如何保证 LLM 评估的**可靠性**，使其提供有意义的教学反馈？

---

## 4. 方法

| 项 | 内容 |
|---|---|
| 数据 | 16 位教师（9 高等数学 + 7 大学物理）的课堂录像，讯飞星火转写 |
| Rubric | 2 个一级指标：**导入内容质量**（准确性、结构、生动性、互动性）+ **例题质量**（挑战性、实用性、进阶性） |
| 量表 | **1~5 档**（与约师一致） |
| LLM | Kimi（Moonshot AI），对比 Qwen、ERNIE |
| 三种 prompt | P1 只给 rubric；P2 + 分步评分指令；P3 + **专家标注的高质量/普通课示例** |

---

## 5. 关键发现

### 5.1 评分示例是成败关键（最重要）

| Prompt | 与期末成绩的相关 |
|---|---|
| P1（只给 rubric） | 几乎全部不显著（仅 Practicality 显著） |
| P2（+分步指令） | 全部不显著 |
| **P3（+评分示例）** | **全部显著**（0.511~0.714） |

→ 光给 rubric 不够，**专家评分示例**才能让 LLM 稳定评分。

### 5.2 幻觉检测：用"反复评估的变异系数"

对每个样本反复评 10 轮，发现「互动性」指标变异系数高达 **19.8%**（其他指标 4~8%）——原因是样本里师生互动少，LLM 在"无信息可评"时产生幻觉。**于是从 rubric 中剔除该指标**。

### 5.3 效度：与期末成绩相关

导入内容质量 0.647、例题质量 0.679（均 p<0.01），两指标合计解释期末成绩 **53.8%** 的方差。

### 5.4 因素分析与聚类

- 因子分析：每个一级指标收敛为**单一因子**（KMO >0.75，累计方差 >82%）
- 聚类：自动分成高质量/普通/预警 3 类，国家级优质课→高质量、新手试讲→预警，与专家判断吻合

### 5.5 模型差异 + 示例敏感

- 模型：Kimi > Qwen > ERNIE
- 示例敏感：篡改示例分数会显著改变结果（F=3.474, p=0.024），**高质量示例影响更大**

---

## 6. 对本项目的作用

### 6.1 约师的最小化同款验证

rubric + LLM + 1~5 档 + 转写评内容 + 效度验证——**几乎就是约师要做的**。这篇小规模跑通了，给约师"路线可行"再加一份实证。

### 6.2 评分 prompt 必须带"示例"（直接教训）

P1/P2（无示例）基本失效，P3（带专家示例）才显著。**约师评分 prompt 除了 rubric，还应收录"高质量讲题样例 + 普通讲题样例"**——这比只写 5×5 分档表更关键。

### 6.3 幻觉检测方法可直接借用

"反复评 N 轮 → 看变异系数 → 剔除高变异指标"——这是**识别不可靠维度**的具体方法，对应约师 NFR-Q6（理由无幻觉）。约师可对每个维度做同款检测。

### 6.4 效度验证的样板

用**期末成绩**（学生结果）而非人工评分员做效度——约师的对应是**成单率/续费率/家长评价**。这篇提供了"效度怎么验"的模板。

### 6.5 因素分析验证 rubric 结构

用因子分析确认各指标收敛为单一因子 → 约师可对 4 维度做同款验证（是否各自独立、是否过度重叠）。

---

## 7. 局限性（须注意）

1. **样本极小**：仅 16 人、2 门课，0.647 的相关在 n=16 下很不稳定，效度结论需谨慎。
2. **只有效度、无信度**：报告了"与成绩的相关"，但**没有报告 LLM 的评分者内/间信度（ICC）**——恰恰是约师 NFR-Q1 最关心的那项，这篇缺失。
3. **单学科**：仅数理基础课，人文类未验证。
4. **示例仍靠专家**：评分示例由专家手写，未自动化——且示例分数被篡改会显著影响结果。
5. **相关 ≠ 因果**：期末成绩受学生背景、教学环境等混杂因素影响（作者自己也承认）。

---

## 8. 关键启示

1. **路线可行**：rubric + LLM + 1~5 档评教学内容，有实证先例。
2. **评分示例比 rubric 本身更关键**：约师 prompt 必须带专家示例。
3. **幻觉可用"反复评估 + 变异系数"检测**：对应 NFR-Q6。
4. **效度要验到"学生结果"**：约师应对标成单率/续费率，而非只对齐人工评分员。
5. **别只看这篇的 0.647**：样本太小、无信度度量，效度数字要打折看。
