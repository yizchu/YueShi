## ① 概念阐释题（试讲环节 · 第一轮）

#### M-CZ-0007 · 七年级 · 有理数的乘法法则（基础）

- **学生人设**：初一，刚学有理数乘法，规则全靠背，爱问"为什么"
- **学生表现**：老师，为什么负数乘负数会变成正数？前面不是说负号越多越小吗？
- **教学目标**：让学生理解"负负得正"的合理性，而不是死记规则
- **评分要点**：
  1. 不回避问题，正面回应
  2. 用可理解的模型解释（相反数的相反数 / 乘法分配律推导）
  3. 回到规则并做验证
  4. 说明这是数学的规定，但有内在一致性
- **常见偏差**：直接说"记住就行""规定就是这样"；或用"负号抵消"这类循环解释
- **建议时长**：8 分钟

#### M-CZ-0008 · 八年级 · 函数的概念（中档）

- **学生人设**：初二，刚接触函数，能算题但说不出定义，害怕抽象符号
- **学生表现**：函数到底是个啥？为什么要写成 f(x)？看着就头大
- **教学目标**：建立"一个输入对应唯一输出"的直观理解
- **评分要点**：
  1. 用"输入—输出机器"或"两个变量的对应关系"作直观类比
  2. 强调核心限制条件：**一个 x 只能对应一个 y**
  3. 举具体例子（y = 2x）并让学生自己举例
  4. 再回到 f(x) 记号的含义
- **常见偏差**：直接背课本定义"设在某变化过程中有两个变量 x、y……"；对初二学生使用集合映射语言
- **建议时长**：10 分钟

#### M-CZ-0009 · 七年级 · 除数不能为零（基础）

- **学生人设**：初一，记性好但只记结论，喜欢钻牛角尖
- **学生表现**：1÷0 为什么不行？那 0÷0 行不行？
- **教学目标**：让学生从运算关系上理解"分母不能为零"，而非死记
- **评分要点**：
  1. 从"除法是乘法的逆运算"切入
  2. 若 1÷0 = a，则 0×a = 1，不存在这样的数 → 无解
  3. 若 0÷0 = b，则 0×b = 0，任何数都成立 → 结果不唯一
  4. 结论：两种情形都不符合"运算结果唯一确定"的要求
- **常见偏差**：只说"规定不能为 0"；或误答"0÷0 = 0"
- **建议时长**：8 分钟

#### M-CZ-0010 · 八年级 · 三角形内角和定理（中档）

- **学生人设**：初二，动手量过角，对"定理"和"测量"的区别没有概念
- **学生表现**：我量出来是 179° 啊，凭什么说一定等于 180°？
- **教学目标**：让学生理解测量不能代替证明，掌握内角和定理的证明思路
- **评分要点**：
  1. 肯定学生的观察，但指出测量有误差、且不能覆盖所有三角形
  2. 用过顶点作对边平行线的方法证明（内错角相等 → 拼成平角）
  3. 强调"任意三角形"与"举例子"的区别
- **常见偏差**：说"这是定理，记住就行"；或只说"大家都这么量"
- **建议时长**：10 分钟

## ② 例题讲解题（试讲环节 · 第一轮）

#### M-CZ-0014 · 九年级 · 一元二次方程的应用（中档）

- **学生人设**：初三，会解方程，但读不懂应用题，习惯直接套公式
- **学生表现**：这种题一看到字多就懵，不知道设什么
- **题目**：某商品原价 100 元，连续两次降价后售价为 81 元，若两次降价的百分率相同，求这个百分率
- **教学目标**：掌握"审题 → 设未知数 → 找等量关系 → 列方程 → 检验取舍"的通用流程
- **评分要点**：
  1. 带学生审题、圈关键词（"连续两次""百分率相同"）
  2. 示范设未知数：设每次降价的百分率为 x
  3. 等量关系：100(1−x)² = 81
  4. 解得 x = 0.1 或 x = 1.9，**舍去 x = 1.9**（降价率不能 ≥ 100%）
  5. 回到通用流程做小结
- **常见偏差**：直接给方程不解释怎么想到的；解出两根后不检验取舍
- **建议时长**：10 分钟

#### M-CZ-0015 · 八年级 · 全等三角形的判定（中档）

- **学生人设**：初二，记住了判定定理但分不清对应关系
- **学生表现**：老师，反正两角一边不就全等吗，为什么要分这么细？
- **题目**：在 △ABC 和 △DEF 中，∠A = ∠D，∠B = ∠E，BC = EF，求证 △ABC ≌ △DEF
- **教学目标**：区分 ASA 与 AAS，理解"对应边"的含义
- **评分要点**：
  1. 指出本题是 AAS（两角及其中一角的**对边**）
  2. 明确 BC 与 EF 是对应边（都是 ∠A、∠D 的对边）
  3. 强调必须找准对应关系，不能机械套用
  4. 对比 ASA 的图形，说明二者区别
- **常见偏差**：直接说"两角一边就全等"，不区分 ASA 与 AAS
- **建议时长**：10 分钟

#### M-CZ-0016 · 九年级 · 切线的判定（中档）

- **学生人设**：初三，混淆切线的"判定"与"性质"，喜欢背结论
- **学生表现**：老师，证切线是不是只要证明垂直就行了？
- **题目**：⊙O 中，OC 为半径，直线 l 经过点 C，且 l ⊥ OC，求证 l 是 ⊙O 的切线
- **教学目标**：准确掌握切线判定定理的两个条件
- **评分要点**：
  1. 明确判定定理：经过半径**外端**且**垂直于**这条半径的直线是圆的切线
  2. 强调两个条件缺一不可（"过半径外端" + "垂直"）
  3. 对照切线的性质定理，说明"判定"与"性质"的方向相反
- **常见偏差**：只证垂直不说明过半径外端；或把判定与性质混为一谈
- **建议时长**：10 分钟

#### M-CZ-0017 · 九年级 · 反比例函数中 k 的几何意义（中档）

- **学生人设**：初三，能算解析式，但几何意义完全没建立
- **学生表现**：老师，这个 k 除了代进去算，还有别的作用吗？
- **题目**：点 P 在反比例函数 y = k/x（k > 0）的图象上，过 P 分别作 x 轴、y 轴的垂线，与坐标轴围成的矩形面积为 6，求 k
- **教学目标**：理解 |k| 的几何意义
- **评分要点**：
  1. 设 P(x, y)，矩形面积 = |x|·|y| = |k|
  2. 由面积 6 得 |k| = 6
  3. 结合 k > 0 得 k = 6
  4. 强调绝对值的作用，并对比一次函数中三角形面积的求法
- **常见偏差**：忽略绝对值，把 k = −6 也写进去；或误用 k/2
- **建议时长**：9 分钟

## ③ 错因诊断题（答辩环节 · 第 2~N 轮）

#### M-CZ-0031 · 八年级 · 分式方程的增根（中档）

- **学生人设**：初二，计算粗心，基础中等，做完题从不检验
- **学生表现**：解 `1/(x-2) + 3 = (x-1)/(x-2)`，去分母得 `1 + 3(x-2) = x - 1`，解得 `x = 2`，写完就交
- **教学目标**：理解增根产生的原因，养成检验习惯
- **评分要点**：
  1. 指出 x = 2 使分母为 0，原方程无意义
  2. 解释增根如何产生（去分母时乘了可能为 0 的式子）
  3. 演示检验步骤
  4. 解释"为什么分母不能为零"
  5. 给出防错建议：解完必须代回最简公分母检验
- **常见偏差**：只说"答案错了，应该是无解"却不解释原因；或试讲者自己也没意识到要检验
- **建议时长**：10 分钟

#### M-CZ-0032 · 七年级 · 去分母漏乘（基础）

- **学生人设**：初一，计算步骤会背，但一遇到常数项就漏
- **学生表现**：解 `(x-1)/2 - (2x+1)/3 = 1`，去分母得 `3(x-1) - 2(2x+1) = 1`
- **教学目标**：理解等式性质，掌握去分母时"每一项都要乘"
- **评分要点**：
  1. 指出右边常数项 1 漏乘了 6
  2. 回到等式性质：两边同乘同一个非零数，**每一项**都要乘
  3. 演示正确过程：`3(x-1) - 2(2x+1) = 6`
  4. 给出防错方法（去分母后用最简公分母通分验证）
- **常见偏差**：只指出"右边错了"就直接给正确答案，不讲等式性质
- **建议时长**：8 分钟

#### M-CZ-0033 · 八年级 · 全等判定的 SSA 误用（中档）

- **学生人设**：初二，刚学完五个判定方法，记混了
- **学生表现**：老师，两边和其中一边的对角相等，不就全等了吗？
- **教学目标**：理解 SSA 不能判定全等，只有 SAS（夹角）成立
- **评分要点**：
  1. 明确指出"边边角"不能判定全等
  2. 给出反例说明（两边及其中一边的对角相等，但两三角形不全等）
  3. 强调 SAS 中的角必须是两边的**夹角**
  4. 带学生回到判定方法的完整清单
- **常见偏差**：只说"书上是这么规定的"，说不清为什么；或自己也认为 SSA 成立
- **建议时长**：10 分钟

#### M-CZ-0034 · 七年级 · 不等式两边同乘负数未变号（基础）

- **学生人设**：初一，解方程很熟，把不等式的规则照搬过来了
- **学生表现**：解 `-2x > 6`，两边同除以 -2，得 `x > -3`
- **教学目标**：理解"乘除负数必须变号"的原因
- **评分要点**：
  1. 指出符号方向错了，正确结果是 `x < -3`
  2. 用数轴验证，或代具体数字检验（如 x = 0 不满足原式）
  3. 解释原因：不等式两边同乘一个负数，大小关系反转
  4. 给出防错方法：不确定时代入数字验证
- **常见偏差**：只把答案改成 `x < -3`，不讲为什么变号
- **建议时长**：8 分钟

#### M-CZ-0035 · 八年级 · 完全平方公式与平方差公式混淆（基础）

- **学生人设**：初二，刚学乘法公式，符号感弱
- **学生表现**：老师，`(a+b)²` 不就是 `a² + b²` 吗？
- **教学目标**：理解完全平方公式的中间项从哪来
- **评分要点**：
  1. 指出漏了中间项 2ab
  2. 用乘法分配律展开 `(a+b)(a+b)` 说明中间项来源
  3. 用面积模型作直观解释
  4. 对比平方差公式 `(a+b)(a-b) = a² - b²`，说明二者适用场景不同
- **常见偏差**：只说"记住中间还有 2ab"，不讲来源
- **建议时长**：9 分钟

## ④ 分层适配题（试讲环节 · 第一轮）

#### M-CZ-0042 · 七年级 · 绝对值的意义（基础 → 拔高）

- **学生人设**：同一知识点需分别讲给两位学生。A：基础薄弱，数轴都不熟练；B：已能熟练化简 |x| 型式子
- **学生表现**：—（对比任务，无单一学生表现）
- **教学目标**：考察同一知识点能否针对不同水平调整讲法
- **评分要点**：
  1. 对 A：用数轴上的"距离"直观解释，避免符号堆砌
  2. 对 B：引入 |x − a| 的几何意义（到 a 的距离），延伸到含绝对值的方程
  3. 能清楚说明"为什么对两人讲法不同"
- **常见偏差**：对两人用同一套讲法；或对 A 直接讲 |x − a| 的几何意义导致听不懂
- **建议时长**：12 分钟

#### M-CZ-0043 · 七年级 · 一元一次方程的应用（基础 → 中档）

- **学生人设**：A：基础弱，习惯算术解法；B：已能熟练列方程
- **学生表现**：—（对比任务）
- **题目**：甲、乙两人相距 30 km，相向而行，甲速度 4 km/h，乙速度 6 km/h，几小时后相遇？
- **教学目标**：考察从算术思维到代数思维的过渡引导能力
- **评分要点**：
  1. 对 A：用线段图直观呈现，先一步一步算，再抽象成方程
  2. 对 B：直接设 x 列方程 4x + 6x = 30，并延伸到追及问题
  3. 说明"为什么对 A 要先直观，对 B 可以直接抽象"
- **常见偏差**：对 A 直接上方程导致听不懂；对 B 讲与 A 相同的内容，没有挑战性
- **建议时长**：12 分钟

#### M-CZ-0044 · 九年级 · 二次函数的最值（中档 → 拔高）

- **学生人设**：A：基础中等，会用配方法；B：已掌握图象与对称轴
- **学生表现**：—（对比任务）
- **题目**：求 y = x² − 4x + 3 的最小值
- **教学目标**：考察能否从"会算"引导到"理解结构"
- **评分要点**：
  1. 对 A：用配方法 y = (x−2)² − 1，得最小值 −1
  2. 对 B：引入对称轴 x = −b/(2a) 与顶点公式，并联系实际最优化问题
  3. 说明两种方法的内在一致性（顶点式与公式同源）
- **常见偏差**：只给公式不讲配方法；或对基础生直接上顶点公式
- **建议时长**：12 分钟

## ⑤ 答疑应变题（答辩环节 · 第 2~N 轮）

> 本类疑问由题目**预置**（可多条、逐轮揭示），在第一轮讲题结束后才揭示给试讲者，全程无需实时语音。

#### M-CZ-0055 · 八年级 · 一次函数的图象与性质（中档）

- **学生人设**：初二，注意力容易分散，一遇抽象概念就想放弃
- **学生表现**：老师讲到"k 决定图象倾斜方向"时打断："老师我有点听不懂了，这个 k 到底有啥用啊？学这个能干嘛？"
- **教学目标**：考察被中断后的情绪稳定、能否降维重讲、能否联系生活
- **评分要点**：
  1. 不慌不乱、不否定学生
  2. 把抽象概念降到具体（"上山 / 下山"坡度，或"话费随通话时长变化"）
  3. 回到数学内容并确认学生是否听懂
  4. 控制节奏，把课上完
- **常见偏差**：重复原话（"k 决定倾斜方向"再说一遍）；或直接跳过说"先记住，以后就懂了"
- **建议时长**：10 分钟

#### M-CZ-0056 · 七年级 · 有理数运算（基础）

- **学生人设**：初一，专注力差，容易被外界影响
- **学生表现**：试讲进行到一半，学生明显走神，被点名后说："啊？老师你刚说什么？"
- **教学目标**：考察课堂管理与拉回注意力的能力
- **评分要点**：
  1. 不指责、不贴标签
  2. 用提问把学生拉回（"刚才我们算到哪一步了？"）
  3. 快速判断是否前面没听懂，必要时回退一步重讲
  4. 调整节奏与互动频率
- **常见偏差**：批评学生"怎么又走神了"；或径直往下讲不管学生状态
- **建议时长**：10 分钟

#### M-CZ-0057 · 七年级 · 除数为零（基础）

- **学生人设**：初一，喜欢试探老师，故意给出错误答案
- **学生表现**：学生自信地说："老师，3÷0 = 0 对吧？因为 3 里面一个 0 都没有。"
- **教学目标**：考察面对错误概念时能否引导自我发现，而非简单否定
- **评分要点**：
  1. 不直接否定，用引导式提问制造认知冲突（"0×0 等于几？如果 3÷0 = 0，那 0×0 应该等于 3 才对"）
  2. 让学生自己发现矛盾
  3. 回到"除法是乘法逆运算"的正向解释
  4. 肯定学生敢于表达的勇气
- **常见偏差**：直接说"错了，记住不能除 0"；或含糊过去留下错误概念
- **建议时长**：9 分钟

#### M-CZ-0058 · 九年级 · 二次函数应用（中档）

- **学生人设**：初三，成绩中等，对学习意义有怀疑
- **学生表现**：学生突然停下说："老师，学这些以后又用不上，为什么要学啊？"
- **教学目标**：考察价值观引导与课堂节奏把控
- **评分要点**：
  1. 不空谈大道理，用具体例子回应（如抛物线在投篮、喷泉、桥拱中的应用）
  2. 坦诚承认不是每个知识点都直接实用，但强调思维训练的价值
  3. 把话题自然带回课堂，不纠缠
- **常见偏差**：空洞说教"以后你就知道了"；或贬低学生"不学以后没出路"
- **建议时长**：10 分钟

## 使用提示

- 每道题的 **「常见偏差」** 是校准低分档的关键，不可省略；缺失时该题的评分区分度会显著下降
- 试讲环节题型（①概念阐释题、②例题讲解题、④分层适配题）的「评分要点」应包含**主动预判并强调易错点**，这是错因诊断能力的**预防面**，不应等学生出错才纠正
- ⑤ 类题型的疑问以**文本形式异步呈现**（可多条、逐轮揭示），第一版即可使用，不依赖实时语音；首条疑问在讲完第一轮后揭示，后续疑问在上一条回应后揭示
- 题库需定期轮换并做泄题检查；每次评估保留音视频与评分记录，回填「AI 分 vs 人工分」差异样本以迭代 rubric
