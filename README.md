# 约师（YueShi）

> **约个好老师** —— 专注大学生家教的信任撮合平台
**同校学长学姐 · 实名可查 · 课时费担保**

## 项目简介

约师是一个双边撮合平台，同时服务两类人：

- **想找家教的人**：学生 / 家长
- **想做家教的人**：在校大学生

它不做"大而全的家教平台"，而是聚焦**大学生家教**这一细分场景，用「信任 + 精准匹配 + 透明低价」打差异化，核心心智是"**同龄人教同龄人、同校学长学姐陪跑**"。

## 要解决的问题（痛点）

| 侧 | 痛点 |
|---|---|
| 家长/学生 | 大学生"不靠谱、假冒"的顾虑；找不到对口专业 / 同校的合适老师 |
| 大学生老师 | 被家长放鸽子、拖欠克扣课时费、接单信息不对称 |
| 行业 | 中介跑路、高额介绍费、价格不透明 |

## 核心竞争力（为什么能做）

1. **信任做成硬资产**：学信网学籍 / 学生证 / 高考单科分数等**可核验背书** + 实人认证 + 试课保障 + 课时费平台担保。
2. **「同校学长学姐」独占心智**：按同高中→同大学、专业对口、目标院校匹配。
3. **透明低价**：不收几百块一次性介绍费，公开地区行情价。

## 目标用户

- **C 端（家长/学生）**：需要上门或线上一对一辅导的中小学生及其家长。
- **C 端（大学生）**：想利用课余时间做家教赚取收入、积累经验的大学生。

## 功能规划（按优先级）

### P0 —— MVP 核心（先做这三件事）

**学生/家长端**
- 注册登录（手机号 / 微信授权）
- 搜索筛选老师：科目、年级、地区、价格、所在大学/专业
- 老师主页：简介、可教科目、学历学籍认证标识、高考分数、评价
- 发布家教需求：科目、年级、时间、预算、地点

**大学生老师端**
- 实名 + 学籍认证（学信网 / 学生证 / 高考成绩佐证）
- 个人简历 / 主页
- 浏览并应征需求

**平台端**
- 认证审核
- 简单匹配（硬条件过滤 + 规则排序）

### P1 —— 上线

- 在线咨询（IM）
- 预约 / 下单 + 试课保障（首课不满意可退可换）
- 课时费平台担保 + 结算
- 课后评价

### P2 —— 增长

- 支付（微信 / 支付宝）
- 学习报告 / 进步反馈
- 续费提醒、推荐位
- 运营后台（订单 / 纠纷 / 内容审核）

## 匹配逻辑

- **硬条件**：科目、年级、地区、价格区间、可上课时间
- **排序规则**：同校/同高中优先 > 专业对口 > 高考分数 > 评分 > 成单量 > 距离

完全用数据库查询 + 简单加权实现，不引入推荐算法。

## 技术方案（简单稳妥、单体优先）

| 模块 | 选择 | 说明 |
|---|---|---|
| 前端 | Vue | 移动端优先，App 可后置 |
| 后端 | FastApi | 不拆微服务 |
| 数据库 | PostgreSQL 或 MySQL | 关系型足够 |
| 文件存储 | 对象存储（阿里 OSS / 腾讯 COS） | 存头像、证件、证书 |
| 即时通讯 | 自研简单版（WebSocket）或接第三方 IM | MVP 可先用轮询 |
| 支付 | 微信 / 支付宝，MVP 先"线下确认" | 降低资质与接入成本 |
| 部署 | 云服务器 + Docker（可选），国内需域名备案 | |
