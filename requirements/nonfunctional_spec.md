## 0. 范围说明

本规范仅覆盖**讲题教学能力评估智能体**（输入为**逐字讲稿 + 3 轮文本问答**）。以下内容**不在范围内**：

- 学科知识准入测试（默认被试已掌握学科知识）
- **人工复核 / 申诉**（属下游产业环节）
- **听觉评估**（连贯性、口齿清晰）
- **视觉评估**（读稿、板书）
- **音视频采集 / 视频转录**
- 家教平台的订单、支付、IM、推荐算法
- 其他学段与学科

> 非功能需求必须**可度量、可验证**。每条均给出目标值与验证方式。
> **注意**：输出必须**可复核**（含逐项理由与证据），供下游开展人工复核——体现在 NFR-Q2。

## 2. 性能需求 (NFR-P)

| 编号 | 需求 | 目标值 | 验证方式 |
|---|---|---|---|
| NFR-P1 | 问题生成时长 | 抽 3 类人设 + 生成 3 问 + 参考要点，**≤ 60 秒**（P95） | 批量压测 |
| NFR-P2 | 单轮问答响应 | 提交回答至下一问揭示 **≤ 10 秒**（P95，问题已预生成时） | 埋点统计 |
| NFR-P3 | 评分时长 | 讲稿 + 3 轮问答全部评分 **≤ 3 分钟**（P95） | 批量压测 |
| NFR-P4 | 端到端出报告 | 第 3 轮回答提交至报告可见 **≤ 5 分钟**（P95） | 全链路埋点 |
| NFR-P5 | 报告页加载 | 首屏 **≤ 3 秒**（P95） | 前端监控 |
| NFR-P6 | 并发能力 | 支持 **≥ 50** 个会话并行不排队 | 压测 |

> **固定 3 轮**：问答轮次固定为 3，不随题目或人设变化，便于性能与成本估算。

| 编号 | 需求 | 目标值 | 验证方式 |
|---|---|---|---|

| NFR-R6 | 幂等性 | 重复提交同一会话不产生重复评分 | 接口测试 |
| NFR-R7 | 讲稿保护 | 讲稿提交后，即使会话中断也不丢失已提交内容 | 故障注入 |

## 6. 评分质量需求 (NFR-Q) —— 核心

> 评分质量不达标，整个系统不成立。

| 编号 | 需求 | 目标值 | 验证方式 |
|---|---|---|---|
| **NFR-Q1** | **与专家评分一致性** | Kappa / ICC **≥ 0.75** | 双评分者一致性统计 |
| NFR-Q2 | 可解释、可复核 | **每个评分项必须附理由与原文证据**；每条采分点给出覆盖判定依据 | 结果结构校验 |
| NFR-Q3 | 可复现性 | 同一输入 + 同一标准版本 + 同一模型版本，档位偏差 **≤ 1 档** | 重复评分实验 |
| NFR-Q4 | 版本可追溯 | 每条评分可追溯到 **标准版本 + 提示词版本 + 模型版本** | 数据核查 |
| **NFR-Q5** | **采分点判定稳定性** | 核心采分点"覆盖/未覆盖"判定，多次评分**一致率 ≥ 90%** | 重复判定实验 |
| NFR-Q6 | 理由无幻觉 | 理由不得引入原文中不存在的内容，不合规率 **< 2%** | 抽样核查 |
| NFR-Q7 | 多轮自一致性 | 同输入评 N 次（N=3，独立无状态），档位一致率 **≥ 90%** | 重复评分 + 方差分析 |
| NFR-Q8 | 区分度 | 各评分项分布标准差 **> 0.8**，避免全给中间分 | 分布统计 |
| NFR-Q9 | 内部一致性 | 同层各维度间 Cronbach's α **≥ 0.7** | 统计分析 |
| NFR-Q10 | 重测稳定性 | 同一人两次评估评级一致或仅差 1 档 | 重测实验 |
| **NFR-Q11** | **门槛规则可靠性** | 核心采分点未覆盖时，评级限制规则**100% 生效**，不被其他项高分覆盖 | 单元测试 + 抽样 |
| NFR-Q12 | 建议相关性 | 改进建议必须**指向实际失分项**，不得凭空生成（抽检相关率 ≥ 90%） | 抽样核查 |

> **Q1 说明**：产品流程不含人工复核；研究阶段仍须用**专家评分**（少量样本）作为验证手段，证明智能体可靠。

## 7. 虚拟学生问题生成质量 (NFR-G)

> 这是本系统区别于"纯讲稿评分"的关键模块，单独列出。

| 编号 | 需求 | 目标值 | 验证方式 |
|---|---|---|---|
| **NFR-G1** | **合理性** | 问题符合所选人设特征且与讲题内容相关，人工抽检通过率 **≥ 95%** | 人工抽检 |
| **NFR-G2** | **互不重复** | 3 问考察点不重叠，抽检通过率 **≥ 95%** | 人工抽检 + 语义相似度 |
| NFR-G3 | 人设区分度 | 同一题目下不同人设生成的问题，类型分布可区分（不趋同） | 分布统计 |
| NFR-G4 | 可答性 | 问题在初中数学范围内可答，抽检通过率 **≥ 98%** | 人工抽检 |
| NFR-G5 | 参考要点完备 | 每个问题同步产出参考应答要点，覆盖率 **100%** | 结构校验 |
| NFR-G6 | 生成可复现 | 同题目 + 同人设 + 同温度，问题主题分布稳定 | 重复生成实验 |

## 10. 成本需求 (NFR-$)

| 编号 | 需求 | 目标值 |
|---|---|---|
| NFR-$1 | 单次评估成本 | 问题生成 + 评分 LLM 调用合计 **≤ 1 元 / 次** |
| NFR-$2 | 算力门槛 | 走 LLM API 即可，**不强制 GPU** |
| NFR-$3 | 存储成本 | 全文本，可忽略 |

> **成本测算**：
> - **问题生成**（1 次）：输入 ≈ 题目 + 人设 + 讲稿（≈4000 tokens），输出 ≈ 3 问 + 参考要点（≈1000 tokens）→ ≈ ¥0.1
> - **评分**（N=3 次独立采样）：输入 ≈ 讲稿 + 3 轮问答 + 标准 + 参照物（≈8000 tokens），输出 ≈ 逐项得分与理由（≈2000 tokens）→ 单次 ≈ ¥0.15，×3 ≈ ¥0.45
> - **合计 ≈ ¥0.55 / 次**，低于 1 元预算。

## 13. 需求优先级与验收

| 优先级 | 编号 | 说明 |
|---|---|---|
| **P0 必须达标** | NFR-Q1、Q2、Q5、Q11、**NFR-G1、G2、G4、G5**、NFR-R1、R2、R3、NFR-S1~S3、NFR-C2~C3、NFR-P1~P4 | 不达标则系统不成立 |
| **P1 重要** | NFR-Q3、Q4、Q6~Q10、Q12、NFR-G3、G6、NFR-R4~R7、NFR-S4~S6、NFR-M1~M5、NFR-O1~O5、NFR-$1~$2、NFR-X1~X3、NFR-U1~U5 | 第一版应有 |
| **P2 可延后** | NFR-M6、M7、NFR-C1、C4、NFR-$3 | 视进度安排 |

### 验收门槛

> **两条红线**：
> 1. **NFR-Q1**：评分与专家一致性 ≥ 0.75
> 2. **NFR-G1 / G2**：生成的问题"合理且互不重复"，抽检通过率 ≥ 95%
>
> 第一条决定"评得准不准"，第二条决定"问得对不对"——两者任一不达标，系统不成立。
