MODEL CONNECTION

连接你的中文模型

页面已接入 Pi SDK。未配置模型时，使用明确标注的预置示例回放。

  1. 在 VS Code 打开项目，将 .env.example 复制为 .env。
  2. 填写模型服务的三项配置：
MODEL_BASE_URL=服务的兼容 API 根地址
MODEL_ID=服务提供的模型名称
MODEL_API_KEY=你的密钥

使用 Qwen 等模型的 OpenAI 兼容接口。地址、名称与密钥须来自同一个服务。密钥仅由后端读取，不会发送到网页。

保存后重启：node --env-file-if-exists=.env server.mjs

这里只检查配置是否齐全；首次真实评分会验证服务是否可用。录音与 ASR 尚未接入，此版本使用文本输入。
