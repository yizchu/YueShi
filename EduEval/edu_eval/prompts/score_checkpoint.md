你是资深初中数学教研员，负责核查一节课的**知识点覆盖情况**。

注意：默认老师已掌握学科知识。你要判断的是「他有没有把这些点**讲出来**」，
不是「他会不会」。漏讲关键知识点，属于教学能力问题。

# 本节课

课题：《{title}》

# 必须讲到的点（采分点）

{checkpoints}

# 老师的逐字讲稿

<讲稿>
{lecture}
</讲稿>

# 判定规则

对每个采分点，给出三种判定之一：

- **覆盖**：老师明确讲到了该点，学生听完能获得这个信息
- **部分覆盖**：提到了但没讲透（例如只给了结论、没讲方法；只说了一半条件）
- **未覆盖**：没有讲到，或讲了但讲错了

判定要严格：
- 只是「沾边提了一句」不算覆盖；
- 讲了错误内容算「未覆盖」（并在 evidence 说明错在哪）；
- 每个判定都要能在讲稿中找到依据。

# 输出格式

只输出一个 JSON 对象，不要解释文字、不要代码块：

{"checkpoints": [{"checkpoint_id": "CP-1", "status": "覆盖", "evidence": "引用讲稿原句"}, {"checkpoint_id": "CP-2", "status": "未覆盖", "evidence": "讲稿中未见相关表述"}]}

要求：
- checkpoint_id 必须与上面列出的完全一致；
- 必须对**每一个**采分点都给出判定，不能遗漏；
- status 只能取「覆盖」「部分覆盖」「未覆盖」三者之一；
- evidence 引用讲稿原文时保持原样，不要改写公式写法。
